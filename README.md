# VK Groups Cleaner

Скрипты для массовой отписки от сообществ ВКонтакте. Работают прямо в браузере, без установки расширений и без токенов API.

## Зачем это нужно

Если в подписках накопились сотни пабликов, чистить их вручную через интерфейс ВК — занятие на вечер. Эти скрипты делают то же самое, но за пару минут:

1. Собирают список всех твоих сообществ в CSV-таблицу.
2. Отписываются от тех, что ты пометил.

## Как это работает

Скрипты используют DOM страницы `vk.com/groups`:

- Находят карточки сообществ по CSS-классам.
- Программно вызывают `mouseover` на кнопке меню (в новой вёрстке ВК меню открывается именно по наведению, а не по клику).
- Кликают по пункту «Отписаться».

Никаких запросов к API ВК не отправляется. Скрипт делает ровно то же, что делал бы ты сам руками, только быстрее.

## Установка

Ничего устанавливать не нужно. Открой [vk.com/groups](https://vk.com/groups) в браузере, открой DevTools (F12) → вкладка **Console**, и вставляй код.

>Если браузер блокирует вставку кода в консоль, введи в неё `allow pasting` (Chrome/Edge) или `разрешить вставку` (некоторые сборки) и нажми Enter.

## Использование

### Шаг 1. Собираем список групп

1. Открой `vk.com/groups`.
2. Прокрути страницу в самый верх (Ctrl+Home).
3. Скопируй содержимое `src/01-collect-groups.js` в консоль, нажми Enter.
4. Скрипт автоматически:
   - Прокрутит страницу до конца, подгружая все сообщества.
   - Соберёт `id`, `name`, `href` каждой группы.
   - Скачает файл `my_groups.csv`.

### Шаг 2. Размечаем, откуда выходить

1. Открой `my_groups.csv` в Excel (или любом табличном редакторе).
2. В колонке `keep` поставь `+` напротив тех групп, **из которых нужно выйти**.
3. Сохрани файл как `my_groups_to_leave.csv` в формате **CSV (MS-DOS)** — важно, чтобы разделитель был `;`.

> **Почему плюс = «выйти», а не «оставить»?** Так безопаснее: если забудешь пометить группу, ты просто из неё не выйдешь. В обратной логике ошибка привела бы к отписке от нужного сообщества.

### Шаг 3. Запускаем отписку

1. Вернись на `vk.com/groups`.
2. Прокрути страницу вверх (Ctrl+Home).
3. Скопируй `src/02-leave-groups.js` в консоль, нажми Enter.
4. В открывшемся диалоге выбери `my_groups_to_leave.csv`.
5. Скрипт прокрутит страницу, соберёт карточки и выйдет из помеченных групп.

В конце в консоли появится отчёт: сколько вышло, сколько пропущено, где были ошибки.

## Настройки

В начале `src/02-leave-groups.js` есть параметры:

```js
const DELAY_AFTER_HOVER = 1000; // пауза после наведения на меню (мс)
const DELAY_BETWEEN = 2500;     // пауза между группами (мс)
```

Уменьшать не рекомендуется — ВК может расценить частые однотипные действия как автоматизацию и ограничить аккаунт.

## Ограничения

- **Приватные (закрытые) сообщества.** Пункт меню может называться иначе («Покинуть сообщество»). В скрипте предусмотрен фильтр по нескольким формулировкам, но часть приватных групп всё равно требует ручного выхода.
- **Заблокированные сообщества.** Для групп с ограничением доступа ВК не отображает кнопку меню — выйти через скрипт не получится.
- **Сообщества, где ты администратор.** Из них нельзя выйти, пока не снимешь с себя права.

## Безопасность

- Скрипты не отправляют данные на сторонние серверы.
- CSV-файл формируется и скачивается локально, в браузере.
- Никаких токенов и логинов не требуется.

## Дисклеймер

Скрипт использует внутреннюю вёрстку страницы ВК, которая может измениться в любой момент. Если селекторы перестанут находить элементы — нужно будет обновить их вручную. Автор не несёт ответственности за возможные последствия использования (включая временные ограничения со стороны ВК).
